Design & Adoption Committee · Session 04 — Ecosystem & Interoperability

A must-have connects
to everything that matters

The committee's mandate for this session: no buyer should ever say "it doesn't talk to our stack." Watcher becomes a hub — paging into every platform teams already live in, feeding the observability estate, and accepting alerts from anything that can send a webhook.

The committee's rule for what "makes sense": integrate where incidents live (chat, ITSM, on-call), where identity lives (IdP, directory), and where data lives (Prometheus/Grafana, Excel/BI, Git) — and give everything else one honest, documented universal adapter instead of a thousand shallow logos.

The committee's interop principles

What keeps this a durable capability rather than a logo wall.

PURE PAYLOADSEvery wire format is a pure function in channels.js — unit-testable without the network, so a platform's format change is a one-file fix with a failing test to prove it.
SAME PIPELINEInbound alerts get full citizenship: correlation, on-call, runbooks, maintenance windows. No second-class "external" path.
TEST BEFORE TRUSTAny channel can fire a synthetic page through the real path — misconfiguration is a clear message, never a silent 3 a.m. failure.
UNIVERSAL ADAPTERWhere no first-class integration exists, the documented generic webhook + event API + token auth means anything scriptable connects today — Zapier, Make, n8n, Power Automate, cron.
DEDUP EVERYWHEREOpsgenie aliases, PagerDuty dedup keys, ServiceNow correlation_ids — re-notifies update the same incident on the far side, never stack duplicates.
