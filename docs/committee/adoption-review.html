02

What the walkthrough surfaced

The platform was functionally complete and genuinely running — so every finding is about the distance between works and adopted: the friction a real person hits in the first ten minutes and the first ten incidents.

The live feed read “awaiting telemetry”

Adoption-critical Tom & Jordan

On a freshly seeded demo the dashboard's Live Events panel was empty — it only showed events arriving after page load. A monitoring tool whose live feed looks dead reads as broken in the exact minutes a buyer decides.

SHIPPED →Feed backfills from real history on load; a new tenant-scoped /events/recent endpoint merges state changes and alert transitions.

Actions gave no confirmation

Adoption-critical Sam & Priya

Acknowledging an alert or deleting a rotation just… happened, or didn't. No success, no failure. Under pressure, silence means “did that work?” and erodes trust in every click.

SHIPPED →A toast system announces every mutating action (success/error), screen-reader-live and reduced-motion aware, wired across alerts and admin.

No fast way to reach anything

Adoption-major Sam, Maya

Navigation meant hunting the sidebar; search was Enter-only and devices-only, with no preview. Operators live on the keyboard — the console didn't meet them there.

SHIPPED →A ⌘K/Ctrl-K command palette fuzzy-jumps to any page or live device, with “/”, vim-style g→key nav, and a “?” shortcut sheet.

Timestamps and colours needed a decoder

Adoption-major Sam, Lena

Alerts showed absolute wall-clock times (mental timezone math mid-incident), and the topology's “node colour = state” had no legend to read it by.

SHIPPED →Relative “12m ago” stamps (absolute on hover) on alerts and the feed; a colour legend on the topology map.

Keyboard & assistive-tech gaps

Adoption-major Lena

Icon-only buttons were unlabelled, there was no skip link, and the keyboard-focus ring was inconsistent — blockers for keyboard users and a procurement checkbox in regulated sectors.

SHIPPED →Skip-to-content link, a consistent :focus-visible ring, aria-labels on icon buttons, and a global reduced-motion guard.

Demo state could evaporate

Correctness found while testing

With the poller running against a not-yet-wired Nagios (an empty status.dat), the streamer reconciled the cache to nothing — blanking every dashboard a few seconds after seeding. A demo that wipes itself is worse than no demo.

SHIPPED →The streamer never evicts on a zero-object parse; an empty engine now means “not wired yet”, not “everything vanished”.

Correctness fix · streamer

An empty engine means “not wired yet”, not “estate gone”

The reconciler evicts objects that disappear from Nagios so ghost inventory can't linger. But a parse with zero objects isn't a mass deletion — it's Nagios not connected yet, or status.dat caught mid-rewrite. Evicting on it blanked every dashboard. One guard fixes it, and it hardens real deploys against a truncated-file blip too.

+ // Guard: a zero-object parse means Nagios isn't wired yet (or the file was
+ // caught mid-rewrite) — NOT that the whole estate vanished. Skip eviction.
- const known = await this.redis.smembers(REDIS_KEYS.stateIndex);
+ const known = parsed.length > 0 ? await this.redis.smembers(REDIS_KEYS.stateIndex) : [];
