02

What 1.0.0-rc.1 is

Six capability pillars, each grown through a committee-reviewed wave and recorded in CHANGELOG.md.

Engine

Correlation-first monitoring on Nagios Core

Drop-in for the existing Nagios estate: live streamer, automatic topology root-cause with child suppression, dedup, flap damping, engine-staleness self-alerting, multi-tenant everywhere.

Incident stack

On-call to status page, in the box

Rotations, ack-SLA escalation, runbooks on every page, one-tap mobile acknowledge, maintenance windows, public status page — the stack others sell as three products.

Enterprise

SSO, tokens, SLA, GitOps, services

OIDC + LDAP with group→role mapping, scoped API tokens, fleet SLA reports with CSV, full config-as-code, hardened systemd units + watcherd supervisor, docker-compose.

Intelligence

Explainable anomalies, self-building topology

Median+MAD dynamic thresholds ("+17.7σ above its 7-day normal"), LLDP auto-topology, a zero-dependency OS agent, push metrics ingest.

Ecosystem

Interconnected to everything that matters

12 outbound channels (Teams Adaptive Cards, Slack, PagerDuty, Opsgenie, ServiceNow, Jira, Discord, Telegram, Google Chat, SMTP, webhook), Alertmanager + generic inbound, Prometheus in and out, one-call channel testing.

Experience

A console operators enjoy

Light/dark, ⌘K palette with actions, guided tour, one-click demo, bulk ack + assignment, saved views, installable PWA, WCAG touches — verified live, both themes.

03

The committee record

Four sessions drove this release; each published its evidence.

Session 02 — Adoption Review walked the first deployed build and shipped the six fixes separating "works" from "adopted" (live feed backfill, toasts, palette, legibility, accessibility, the demo-eviction guard).

Session 03 — Market Position assessed ten competitors with current research, sharpened the positioning — "the modern, self-hosted console for teams who outgrew Nagios but won't move to SaaS observability" — and sequenced the gap-closing roadmap that later waves executed to done.

Session 04 — Ecosystem & Interoperability made interconnection a first-class capability: pure payload builders, full-citizen inbound alerts, test-before-trust, dedup on every far side.

Session 05 — this report closes the loop: security review (a real SSO takeover path found and fixed), ingest rate limiting burst-verified, the performance baseline, versioning, docs, and the final all-green verification.

04

Post-1.0, by decision

Nothing here blocks the market. Each is a scope choice, recorded with its reasoning.

DECIDEDSAML — OIDC covers ADFS/Entra/Okta/Keycloak; hand-rolled XML-DSig is a security liability. Revisit via a vetted library on deal demand.
SCOPELogs, APM/tracing, cloud-provider APIs — outside the wedge on purpose; full-stack observability buyers should buy Datadog or the Grafana stack. Watcher feeds and receives those stacks instead of imitating them.
LATERNative mobile app — signed-link ack + the installable PWA already cover the on-call moment; a push-capable app is a growth item, not a launch item.
